## 云控制台恢复

通过 ECS 控制台查看 VNC 或串口报错。若卡在新内核启动，重启一次；一次性 next_entry 正常经过 GRUB 后会被清除，默认 saved_entry 是旧 Ubuntu 内核。如果仍无法启动，在 GRUB 的 Advanced options for Ubuntu 中选择 Ubuntu with Linux 5.15.0-117-generic。

SSH 恢复后检查实际运行状态：

```bash
uname -r
uptime
ip -br addr show eth0
grub-editenv list
findmnt -T /data/cubelet
ls -l /dev/kvm
lsmod | grep kvm
journalctl -b -p err --no-pager
journalctl -b -1 -p err --no-pager
```

旧内核若受新增启动参数影响，启动配置备份为 /root/cube-install/grub.before。需要恢复参数时，先保留当前配置，再恢复备份并 update-grub；不要删除原内核。
